# Sales Analytics Dashboard Using Microsoft Excel

## Project Overview

This project presents an interactive Sales Analytics Dashboard
developed using Microsoft Excel.

The dashboard analyzes sales performance, profitability,
product categories, inventory stock levels, monthly profit,
and store-wise performance.

It helps users explore business performance and identify
sales and profit trends through interactive visualizations.

## Project Objectives

- Analyze total sales, cost, and profit.
- Calculate profit margin and average order value.
- Track total units and transactions.
- Compare revenue across product categories.
- Analyze monthly profit trends.
- Identify top-performing products.
- Analyze stock availability.
- Compare profit across store cities.

## Tools and Techniques

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Excel Slicers
- KPI Cards
- Data Visualization

## Dashboard Features

### 1. Sales Performance
Displays total units, total cost, sales, profit,
profit margin, average order value, and transactions.

### 2. Revenue by Product Category
Compares cost, sales, and profit across product categories.

### 3. Monthly Profit Analysis
Shows monthly profit trends to identify stronger
and weaker periods.

### 4. Top 10 Products by Sales
Highlights products with high sales performance.

### 5. Low Stock Analysis
Displays products categorized by stock availability.

### 6. Profit by Store City
Compares profit performance across store cities.

### 7. Store-wise Profit
Provides a detailed comparison of profit across stores.
